## ¿Qué se necesita?

Para desarrollar en <u>Rust</u>, se requiere de un único ejecutable que realiza la instalación de las herramientas necesarias.

Este ejecutable es <u>rustup</u>, y lo encontraréis en su página oficial rustup.rs.
(En Windows, se necesita una cosa extra. En la propia página lo tenéis informado).

Ya tenéis las herramientas mínimas necesarias. Como IDE podemos usar desde Fresh (Terminal), Visual Studio Code, NeoVim, etc.

## Instrucciones básicas

Herramientas mínimas para crear nuestra primera aplicación: <u>rustup</u> y <u>cargo</u>.

El comando <u>rustup</u> puede realizar múltiples operaciones, pero por ahora lo vamos a dejar en que, básicamente, podemos actualizar a la última versión disponible mediante la siguiente llamada:

```bash
rustup update
```

Para crear un nuevo proyecto, usaremos el comando base <u>cargo</u>:

```bash
cargo new nuevo_proyecto
```

Podemos especificar si queremos crear un ejecutable o una librería:

```bash
cargo new --bin nuevo_proyecto
cargo new --lib nueva_libreria
```

También existen los <u>workspaces</u>, pero eso será más adelante, cuando los proyectos lo requieran.

## Librerías

Las librerías en <u>Rust</u> se llaman crates, y podemos consultar las disponibles oficialmente en la web de [crates.io](https://creates.io).

Si deseamos incorporar una de las librerías a nuestro proyecto, deberemos hacer lo siguiente:

```bash
cargo add libreria_deseada
```

Esta es la base para empezar a desarrollar.
